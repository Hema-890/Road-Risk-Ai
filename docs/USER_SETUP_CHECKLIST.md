## A. ACTIONS REQUIRED FROM ADIL (Only You Can Do)

These items require account creation, email confirmation, CAPTCHA, or secret generation:

- [ ] **1. (OPTIONAL) MapTiler Account for Premium Vector Cartography**
  - **Why:** If you want MapTiler's proprietary Navigation or 3D terrain styles instead of our default OpenFreeMap vector tiles.
  - **Where:** [https://cloud.maptiler.com/](https://cloud.maptiler.com/) (Sign up with Email/Google).
  - **Action:** Create free account (100,000 requests/month free). Copy API Key.
  - **Where It Goes:** Paste into `.env.local` as `VITE_MAPTILER_KEY=your_key_here`.

- [ ] **2. (OPTIONAL) Supabase Project for Cloud Database & Realtime Auth**
  - **Why:** If you want cloud PostgreSQL persistence and hosted authentication instead of the local SQLite database (`roadrisk.db`).
  - **Where:** [https://supabase.com/dashboard](https://supabase.com/dashboard) (Sign up with GitHub).
  - **Action:** Create a new free project named `roadrisk-ai`.
  - **Where It Goes:** Copy Project URL & `anon` key into `.env.local`:
    ```env
    VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
    VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsIn...
    SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsIn...
    ```
  - **Database Migration:** Run the SQL file generated by Antigravity at `supabase/migrations/20260919000000_roadrisk_core_schema.sql` in the Supabase SQL Editor.

- [ ] **3. (OPTIONAL) Google AI Studio API Key for Gemini Natural Language Debriefs**
  - **Why:** If you want Gemini 1.5 Flash to write narrative medical debrief reports instead of our deterministic math debrief engine.
  - **Where:** [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey).
  - **Action:** Generate free API key (15 requests/minute free).
  - **Where It Goes:** Paste into `.env.local` as `GEMINI_API_KEY=AIzaSy...` (Backend only).
